Biblioteca Digital

Aplicación web de gestión de un catálogo de libros, préstamos y devoluciones.
Permite buscar, filtrar y ordenar libros, prestarlos a personas con un límite de
tres préstamos activos, devolverlos y consultar el historial. Incluye un formulario
para agregar y editar libros con validaciones, un resumen estadístico con libros por
género y ajustes de usuario (nombre y tema claro/oscuro). Toda la información se
guarda automáticamente en el navegador mediante localStorage, por lo que se conserva
al recargar la página.

Tecnologías: HTML5, CSS3 y JavaScript (sin librerías externas)  
Uso: abrir `index.html` en el navegador.
